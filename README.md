## Описание курса 

Введение в философию Нового времени через одну из центральных ее проблем ‐‐ отношение между умом и миром. Мы начинаем с механицизма и рассматриваем попытку Декарта предложить его метафизическое и эпистемологическое обоснование. Затем мы прослеживаем проблемы, возникающие из картезианского решения, и различные ответы на них, выходя к центральному эпистемологическому вопросу, ставшему уже одним из главных вопросов и вызовов для философии XVIII века: как идеи могут обеспечить познавательное отношение ума к миру. 


## Отчетность 

Экзамен, 3 вопроса в билете из вопросов к занятиям (1 по Декарту (1‐6), 1 по занятиям 7‐15, 1 по Юму (16‐17))

Коллоквиум, устная защита одного из тезисов, предложенных в «Заданиях». 
Номер тезиса соответствует номеру занятия. 
В качестве ответа ожидается доказательство тезиса с привлечением первоисточника/вторичной литературы. Доказательство должно иметь форму аргумента, а не просто пересказа источника или апелляции к авторитету [Подробнее в презентации 1.1]
